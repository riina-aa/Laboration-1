# Laboration 1 | Backendbaserad webbutveckling

I den här uppgiften så har vi fått göra en serverbaserad webbapplikation som går ut på att skapa ett CV. 
Vi har därför fått öva på hur man kan skapa en webbapplikation som tillåter användare att spara och lagra kurser som de har studerat för att sedan kunna skriva ut dem i applikationen. 

Databasen som användes i denna laboration är via render.com och deras tjänst för Postgre.
